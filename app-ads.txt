# Authorized Sellers for Apps (IAB). It tells ad exchanges which accounts are
# allowed to sell this publisher's app inventory, which is what stops a spoofed
# copy of an app from being sold as if it were ours.
#
# WHERE THIS FILE HAS TO LIVE
# ---------------------------
# Google's crawler reads it from the ROOT of the developer-website domain, not
# from a subfolder:
#     https://hosam77hasan.github.io/app-ads.txt        <-- the address that counts
# The copy in this repository is served at
#     https://hosam77hasan.github.io/-hosam-privacy-policy/app-ads.txt
# and the canonical copy — the one that is actually at the domain root — lives in
# the user-site repository `Hosam77hasan.github.io`. Keep the two identical.
#
# BEFORE PUBLISHING — the one line that matters
# ---------------------------------------------
